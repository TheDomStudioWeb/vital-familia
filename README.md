# Vital · salud y movimiento en familia

App gratuita de salud y ejercicio para la familia: preparación diaria, rutinas que aprenden de cada persona, muñeco 3D que muestra cada ejercicio, reto familiar y lectura del reloj vía Health Connect.

- **Web / PWA:** `public/` → `firebase deploy` → https://vital-familia.web.app
- **APK Android:** cada push a `main` compila en GitHub Actions y publica `Vital.apk` en *Releases*.
- **Secretos del repo (Settings → Secrets and variables → Actions):** `GOOGLE_SERVICES_JSON`, `VITAL_KEYSTORE_BASE64`, `VITAL_KEYSTORE_PASSWORD`.
- Manual interno: `MANUAL-VITAL.md`.
